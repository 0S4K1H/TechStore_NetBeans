# Instaladores y dependencias

Carpeta para dependencias técnicas del proyecto TechStore.

## Debe incluir

- JDK 21
- Apache NetBeans
- Apache Tomcat 10.1
- MySQL Connector/J
- utilidades portables usadas por el proyecto

## Regla

No mezclar aquí código fuente. Solo instaladores, librerías y herramientas.
